# Provider Selection — Early Proposal

## Context

The Atlas Lantern team needed a hosted model for a synthetic document-review
pilot. The first comparison was made before the regional data boundary and
on-call ownership were written down.

## Candidate View

Borealis B was the early favorite because its prototype returned structured
JSON quickly and required little adapter code. This note records a proposal,
not an adoption decision.

## Open Questions

The team still needed evidence about data residency, operational ownership,
and the cost of keeping a fallback provider. The proposal was superseded by a
later comparison review.
