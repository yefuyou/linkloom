动态内容（来源名、原文、对象、模型原始解释、哈希、审批身份）按对应 A/B/D/E 数据类型保留，不改写其语义，不以模板翻译替换数据。未改动 F/G/Runtime/Reviewer/P4、生产 Python 状态转换或任何历史评测材料。
