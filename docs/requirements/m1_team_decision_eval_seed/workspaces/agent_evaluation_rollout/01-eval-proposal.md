# Agent Evaluation — Initial Proposal

## Proposal

The draft proposed using an LLM judge as a release gate and suggested a
next-action score threshold of 0.80. These were planning ideas, not approved
release rules.

## Rationale

The author expected a judge to capture helpfulness that exact deterministic
checks might miss. No reproducibility study or owner assignment was attached.

## Open Questions

The review still needed to decide which metrics were deterministic, how judge
variance would be handled, and whether the next-action threshold had an
approver.
