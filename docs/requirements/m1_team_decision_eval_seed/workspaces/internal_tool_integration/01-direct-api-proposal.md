# Internal Tool Integration — Direct API Proposal

## Proposal

The first draft proposed a write-enabled direct API because it looked simpler
than maintaining a connector and export boundary.

## Concerns

The proposal did not provide a sufficiently narrow permission boundary or an
audit trail for a read-only workflow. It was sent to security review before any
approval.

## Decision Status

This note records an early proposal only. It does not authorize direct writes
and was superseded by the integration decision.
