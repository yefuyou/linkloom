## Reproduction and limits

Run `tests/integration/test_strategy_offline_promotion.py` with pytest. Unique
retained roots/store IDs are emitted with `-s`; hashes above are one actual
verified run, not constants recomputed to bless request-supplied evidence.
Producer manifest pins establish immutable file consistency, not oracle truth.
Independent host suite/key/verifier establishes oracle issuance; consumers freshly
verify its signature, exact outcome/proof matrix, artifacts and upstream approvals.

The six-source saturation fixture is synthetic only for hard-bound tests;
every record genuinely completes its durable test lifecycle, but this is not
six real lessons or approvals. No production accepted Strategy currently
exists. Original historical inputs are local, not distributed with this
feature; only those tests skip if that immutable local evidence is absent.
Live efficacy, full entailment/scope/inference oracles, tokenizer, real human
record approval and production wiring are deferred. `insufficient_evidence`
is an expected, valid outcome of the governed foundation.
