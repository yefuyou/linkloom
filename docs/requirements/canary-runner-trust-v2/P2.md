# P2 quote-scope repair

Date: 2026-10-23
Baseline: `71ccecf937ffc0deb127e252eeff56df00dd4723`
Scope: `src/linkloom/semantic_ingestion/text_scopes.py` and focused quote-scope regressions only.

## Finding

The existing structural scanner treated an apostrophe at the beginning of a
spoken elision (`'round`, `'Cause`, and `'Kay`) as an opening single quote. An
unclosed stack entry then masked the remainder of an AMI chunk, which could
turn an asserted task into a false `NON_ASSERTED_TASK` veto. Historical
diagnostics at
`work/ami-real-semantic-canary/docs/evaluation/ami_semantic_canary_v1/analysis/veto_diagnostics.json`
show the affected ES2002a and ES2005c claims with ranges extending from these
spoken prefixes to the end of the chunk. The corresponding transcript source
was checked in
`work/ami-real-semantic-canary/docs/evaluation/ami_semantic_canary_v1/live/sources.json`.

## Repair

- Keep contractions and possessives (`don't`, `I'm`, `I'll`, `let's`, and
  `owner's`) out of the structural quote stack.
- Recognize common unmatched ASCII leading spoken elisions as literal
  apostrophes. Prefer a complete same-line quote, including quoted elision words;
  keep typographic opening quotes structural.
- Track symmetric quote delimiters with local open/close context so paired
  same-delimiter nested quotes retain the complete outer scope.
- Preserve conservative end-of-input masking for genuinely unclosed quotes,
  exact Unicode offsets, Markdown block/inline code masking, and escaped
  delimiters.

No task identity, source registry, authorization, UNKNOWN, P4, historical, or
raw evaluation implementation was changed.
